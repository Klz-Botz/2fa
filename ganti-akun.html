Cara Ganti Data Akun

Panduan lengkap mengganti email, password, dan pengaturan keamanan akun Rockstar kalian. Ikuti tiap langkah dengan teliti.

1
Login ke Rockstar
Buka website resmi Rockstar Games, lalu login menggunakan akun yang sudah kalian punya.
rockstargames.com
2
Ke Manage Account
Setelah login, buka halaman Manage Account atau pengaturan akun dari menu profil kalian.
Tap untuk memperbesar
3
Klik Email
Di halaman Manage Account, pilih menu Email untuk mulai mengganti alamat email.
Tap untuk memperbesar
4
Ikutin List Ini
Isi kolom-kolom yang tersedia sesuai panduan berikut:
New Email — Email baru atau email kalian yang ingin menjadi penggantinya.
Current Password — Password yang dikasih dari admin.
Enter Authenticator Code — Kode 2FA.
Tap untuk memperbesar
5
Ganti Keamanan 2FA
Jangan lupa untuk mengubah pengaturan keamanan 2FA setelah email diganti.
Tap untuk memperbesar
6
Ganti Password
Isi kolom-kolom berikut untuk mengganti password:
Current Password — Password yang dari admin atau web.
Enter Authenticator Code — Kode 2FA.
New Password — Masukin password baru kalian.
Tap untuk memperbesar
7
Syarat Password
Kalian harus ikutin perintah Rockstar. Password harus memenuhi semua syarat berikut:
Minimal 8 karakter
Tidak boleh melebihi 30 karakter
Mengandung minimal satu huruf kecil
Mengandung minimal satu huruf besar
Mengandung minimal satu angka
Tap untuk memperbesar
7
Konfirmasi & Simpan
Confirm New Password — Masukin lagi password baru kalian.
Klik Save Changes untuk menyimpan perubahan.
Berhasil disimpan? Kalau muncul notifikasi sukses, data akun kalian sudah diperbarui. Login ulang untuk memastikan.

Kalau ada langkah yang tidak bisa diikuti atau muncul error, hubungi tim support kami.
